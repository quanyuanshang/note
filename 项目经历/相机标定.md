
# 项目概述

这是一个**无需标定板的机械臂手眼标定系统**（Hand-Eye Calibration），用于计算机械臂末端执行器与相机之间的空间变换关系。

---

## 核心目标

传统手眼标定需要**标定板**（棋盘格），但本项目通过 **Dust3R**（深度学习三维重建）实现：

1. 从多视角图像重建 3D 场景
2. 估计相机位姿
3. 结合机械臂位姿数据，求解手眼变换矩阵

---

## 工作流程

### 1️⃣ **数据采集**

- 机械臂移动到多个位置拍摄场景
- 记录每个位置的**末端执行器位姿**（来自机器人控制器）
- 保存**相机图像**

- 匹配机械臂位姿与相机位姿对

### 4️⃣ **手眼标定求解**

关键数学问题：**AX = XB**

- `A`: 机械臂相对运动
- `B`: 相机相对运动
- `X`: 手眼变换矩阵（相机→末端执行器）

#### 多种求解方法

methods = [

    ("baseline", baseline_solve_with_given_noise),  # 传统闭式解

    ("RANSAC", ransac_solve_with_given_noise),      # 鲁棒估计

    ("M-est", M_solve_with_given_noise),            # M 估计器

    ("NN", nn_deepsets.deepsets_solve_with_given_noise)  # 深度学习

]

#### 尺度估计

Dust3R 输出的相机位姿存在**尺度模糊**（metric ambiguity），通过：

T_final, scale_final = run_calibration(exp_name, num_imgs)

- 在 `[s_min, s_max]` 范围内搜索最优尺度
- 使用旋转+平移误差作为优化目标

### 5️⃣ **坐标系对齐**

world_pose = estimate_world_alignment(eef_poses, cam_poses, handeye_T)

dust3r_pose, dust3r_ptc = transpose_poses_ptc(im_poses_tor, ptc_tor, world_pose)

- 将 Dust3R 坐标系对齐到**机械臂基座坐标系**
- 使用 SVD 求平均旋转 + 平移均值

    rels = []

    for i in range(len(poses_tor) - 1):

## 核心创新点

1. **无需标定板**：利用 Dust3R 自监督学习估计相机位姿
2. **多算法对比**：集成传统方法（RANSAC）和深度学习方法（DeepSets）
3. **鲁棒性测试**：完整的噪声注入 + 合成数据评估框架
4. **交互式可视化**：点云与图像联动显示

该项目适用于**机器人视觉系统部署**，降低标定成本，提高自动化程度。
