### 4.1 基于提示的注意力模型 (Prompt-Based Attention Model, PAM)

这一节介绍了 PAM 模型，它是 VADIS 的核心，负责根据用户的提示（Prompt）生成动态的文档嵌入和相关性分数。
**核心目标**：传统的文档嵌入是静态的（static），无法根据用户的查询改变。PAM 的目的是让文档的向量表示能够根据用户的 Prompt（提示语/查询）动态调整，并计算出文档与该 Prompt 的相关性。

- **4.1.1 文本编码器 (Text Representations with Encoders)**
    
    - **双编码器架构**：考虑到提示语（Prompt）和文档在长度和语调上的差异，模型使用了两个独立的编码器：$E_{P}(\cdot)$ 用于编码提示语e_p，$E_{D}(\cdot)$ 用于编码文档中的每个 token。$e_{t_{ij}}$
        
    - **灵活性**：$E_{P}$ 可以是任意生成句子嵌入的语言模型，$E_{D}$ 可以是任意生成 token 嵌入的预训练 Transformer 2。
        
- **4.1.2 注意力层 (Attention Layer)**
    
    - **目的**：为了学习提示语与重要 token 之间的关系，在编码器之上增加了一个注意力层 3。
        
    - **计算机制**：利用可学习的矩阵 $W^{Q}$ 和 $W^{K}$ 将提示语和 token 嵌入转换为查询向量和键向量，通过点积计算注意力分数.![[image-24.png]]
    >参数解释：$e_p$：提示语的向量表示。
    >$e_{t_{ij}}$：文档 $j$ 中第 $i$ 个词（Token）的向量表示。
    >$W^Q, W^K$：可学习的权重矩阵==，分别将提示语和文档 Token 映射到查询（Query）和键（Key）空间 4==。通过这两个矩阵，提示语和文档词都被转换到了**同一个数学空间**里，这样它们就可以进行公平的比较了 。
    >公式含义：这本质上是一个点积注意力机制。它计算提示语向量与文档中每一个词向量的相似度。点积结果越大，说明这个词与提示语的关系越紧密（即模型应该“注意”这个词）
        
    - **相关性计算**：文档 $d_j$ 相对于提示语 $p$ 的相关性分数定义为该文档内所有 token 的注意力分数之和。![[image-25.png]]
        
    - **动态嵌入生成**：通过对注意力分数进行 softmax 归一化作为权重，对 文档的token 嵌入进行加权求和，生成与提示语上下文对齐的动态文档嵌入。**作用**：生成的文档向量 $e_{d|p}$ 不再是固定的，而是**包含了用户查询意图的**。例如，同样一篇关于“阿司匹林副作用”的文章，如果你问“副作用”，向量会侧重描述副作用的词；如果你问“阿司匹林”，向量会侧重药物名称。![[image-26.png]]
        
- **4.1.3 损失函数 (Loss Functions)**
    
    - **训练目标**：增强模型根据相关性关注 token 的能力。模型不直接训练 token 级别的注意力，而是通过训练文档级别的相关性来隐式优化 7。
        
    - **对比学习**：采用对比学习方法，将相关文档作为正例 ($d^{+}$)，不相关文档作为负例 ($d^{-}$)，最小化损失函数以区分二者 8888。![[image-27.png]]
    - 这个相关性评分是通过 **prompt 与文档中每个 token 的 attention 分数**累加得到的。 但注意：**loss 并不是直接优化 token-level attention，而是通过优化文档级相关性间接训练 attention 权重。**
    > 公式含义：$d^+$：正例（与提示语相关的文档）。$d^-$：负例（随机抽取的无关文档）10。
    - 为什么要这样做：直接告诉模型“哪个词最重要”很难（没有这种标注数据）。但我们可以很容易知道“哪篇文章是相关的”。通过强迫模型让正例的相关性分数 $r(p, d^+)$ 变大，负例的分数变小，模型就会自动学会去关注文档里那些真正决定相关性的关键词 11。
        
- **4.1.4 实现细节 (Implementation Details)**
    
    - **模型架构**：使用 BioBERT 初始化编码器，因为它是基于生物医学文献预训练的 9。
        
    - **数据集**：使用了 SQUAD、TriviaQA、NaturalQA 和 emrQA（医疗问答数据集）10。
        
    - **数据转换**：将问答数据集转换为 (问题, 正例上下文, 负例上下文) 的形式用于训练 11。![[image-28.png]]
        

### 4.2 保持相关性的文档地图 (Relevance-preserving Document Map)

这一节介绍了一种新的可视化布局方法，旨在同时展示文档的相关性和语义相似性。

- **4.2.1 设计逻辑 (Design Logic)**
    
    - **圆形网格布局**：采用圆形布局，地图中心代表查询的焦点。文档离中心越近，相关性越高 12121212。
	    - 第一步：初始化圆形网格 
	    - 怎么做：创建一个圆形的网格布局，中心留空（作为查询焦点）。
			为什么要这样做：在生物医学检索中，高度相关的文档通常很少（在中心），而不太相关的文档很多（在边缘）。圆形布局符合这种“少而精到多而杂”的分布规律 。
        
    - **空间分布含义**：文档间的距离反映语义相似性 13。
        
    - **网格化**：为了解决传统散点图的遮挡问题，采用网格布局以提高清晰度 14。
        
- **4.2.2 映射算法 (Relevance-preserving mapping)**
    
    - **核心思想**：类似于自组织映射 (SOM) 的竞争学习机制，但增加了相关性参数 $\gamma_{j}$ 15151515。
        
    - **映射过程**：
        
        1. **初始化**：初始化网格单元，中心留空，单元的相关性值初始化为与中心距离成反比 16。
            
        2. **竞争匹配**：将文档分配给能最小化加权距离（结合了嵌入相似性权重 $\omega_{s}$ 和相关性权重 $\omega_{r}$）的空闲单元 17171717。![[image-29.png]]
            > $\omega_s, \omega_r$：相似性权重和相关性权重（用户可调）。$e_d, r_d$：文档的向量和相关性分数（来自 PAM 模型）。==$w_j, \gamma_j$：格子 $j$ 的特征向量和相关性值。==
            > **公式含义**：这是一个**加权距离公式**。系统在寻找格子时，不仅看这个格子的向量是否和文档相似（$||e_{d}-w_{j}||$），还要看这个格子的“相关性层级”是否和文档匹配（$||r_{d}-\gamma_{j}||$）。
        3. **权重更新**：当文档分配给某单元后，更新该单元及其邻居的权重向量 $w$，使其更接近文档嵌入 18。$w_{k}$（网格单元的位置向量）的使命：$w_{k}$ 代表了网格单元 $k$ 在高维语义空间中的**“理想位置”**。当我们将文档 $d$ 分配给单元 $k$ 时，我们是说 $d$ 的语义最接近 $w_k$ 所代表的语义。所有相邻的网格单元 $w_k$ 向量也应该在高维空间中相邻。这保证了 2D 地图的拓扑结构（即邻近性）与原始高维数据的语义结构一致。$\gamma_{k}$（网格单元的相关性值）的使命：它代表了网格单元 $k$ 所处圆环（层）的预期相关性。这确保了布局不仅基于语义，还基于 VADIS 的另一个重要标准——相关性（越靠近中心 $\gamma_k$ 越高）。
	        1. weights更新![[image-30.png]]
	        > **含义**：当你把文档放入格子 $j$，该格子及其邻居 $k$ 的向量 $w$ 都会向文档向量 $e_d$ 靠拢。这保证了邻近区域的语义平滑过渡
	        2. relevance更新![[image-31.png]]
	        > **为什么要这样做**：初始化的网格相关性是假设的（中心是1，边缘是0）。通过这个公式，网格会根据实际放入的文档数据调整自己的相关性值。如果某一层放入了很多低相关性文档，这一层的 $\gamma$ 就会自动降低，从而更真实地反映数据分布 17。
    > $T_{k,j}(t)$（拓扑邻域函数 / 牵连程度）：这是一个关于距离的函数（通常是高斯函数）。核心逻辑：当你用力拉网上的一个结（获胜单元 $j$）去够地上的钉子时，它周围的结（邻居 $k$）也会被带着动。离 $j$ 越近的邻居，$T$ 值越大，被拉动的幅度越大；离得远的，$T$ 值很小，几乎不动。这保证了地图的平滑性，让相似的文档在地图上能聚在一起 5。$lr(t)$（学习率 / 拉力大小）：这控制了更新的步长。随着训练时间 $t$ 的推移，这个值会越来越小。刚开始时是大刀阔斧地调整（粗调），后期是微调，让地图稳定下来 6。
            
        4. **相关性更新**：同时更新同层网格单元的相关性值 $\gamma$，使其更符合数据的真实相关性分布 19。

### **Part 3: 核心方法流程 (Core Method Pipeline)**

**[Slide 4: Pipeline Overview]**
接下来我们深入 VADIS 的核心 Pipeline。整个过程可以分为四个步骤：编码、注意力机制、损失函数优化，以及最终的地图映射。

#### **1. 文本编码器 (Text Representations with Encoders)**
**[Slide 5: Encoders]**
首先是输入层。VADIS 采用了**双编码器架构**。
*   既然 Prompt（查询）通常很短，而 Document（文档）很长且语气不同，模型使用了两个独立的编码器 $E_P$ 和 $E_D$。
*   $E_P$ 负责编码用户的提示语。
*   $E_D$ 负责编码文档中的每一个 Token。
这一步的目的是将自然语言转化为计算机可理解的向量序列。

#### **2. 注意力层 (Attention Layer)**
**[Slide 6: Attention Mechanism]**
这是模型最精彩的部分。
*   **映射到同一空间**：模型利用可学习矩阵 $W^Q$ 和 $W^K$，分别将提示语向量和文档 Token 向量映射到查询（Query）和键（Key）空间。这使得它们可以在同一个数学空间里进行“公平比较”。
*   **计算相关性**：通过**点积 (Dot Product)** 计算 Prompt 与文档中每个 Token 的相似度。如果点积结果大，说明这个词与用户的意图高度相关。
*   **动态嵌入生成**：最后，通过 Softmax 归一化得到注意力分数，并以此为权重，对文档 Token 进行加权求和。
    *   **关键点**：这里生成的文档向量 $e_{d|p}$ 是**动态的**。它不再是死板的全文平均，而是“包含了用户查询意图”的向量。

#### **3. 损失函数 (Loss Function)**
**[Slide 7: Loss Function]**
大家可能会问：我们没有“哪个词更重要”的标注数据，怎么训练这个注意力机制呢？
*   VADIS 采用的是**对比学习 (Contrastive Learning)**。
*   我们虽然没有 Token 级别的标签，但我们有文档级别的标签（即这篇文章是否回答了这个问题）。
*   **训练逻辑**：我们将相关的文档作为正例 ($d^+$)，随机抽取的无关文档作为负例 ($d^-$)。
*   **Loss 设计**：优化目标是**最大化**正例的相关性分数，**最小化**负例的分数。通过这种文档级的优化，模型会由上而下地“隐式学会”去关注文档内部那些真正决定相关性的关键词。

#### **4. 实现细节 (Implementation Details)**
**[Slide 8: Details]**
*   在具体实现上，作者使用了 **BioBERT** 初始化编码器，因为该工作主要针对生物医学领域。
*   训练数据使用了 SQUAD、emrQA 等知名问答数据集，将其转化为 (Question, Positive Context, Negative Context) 的三元组形式进行训练。

### **Part 4: 保持相关性的文档地图 (Relevance-preserving Document Map)**

**[Slide 9: Document Map Concept]**
最后，模型生成的动态向量怎么展示给用户？作者设计了一种新的**圆形网格布局**。

**[Slide 10: Design Logic]**
*   **布局逻辑**：这是一个同心圆结构。
    *   **圆心**代表查询的焦点（Relevance = 1）。
    *   文档离中心越近，相关性越高；离边缘越近，相关性越低。这符合检索场景下“高相关文档少而精，低相关文档多而杂”的规律。
*   同时，文档之间的**空间距离**依然代表语义相似性。

**[Slide 11: Mapping Algorithm]**
*   **算法核心**：这是一个改进版的**自组织映射 (SOM)**。
*   在把文档放入网格时，算法使用了一个**加权距离公式**：
    $$ \text{Distance} = \omega_s \cdot (\text{语义差异}) + \omega_r \cdot (\text{相关性差异}) $$
    这意味着，一个文档要找到它的“位置”，不仅要看它和周围文档像不像（语义），还要看它配不配待在这个相关性层级（相关性）。

**[Slide 12: Updating Rules]**
*   **动态更新**：类似于 SOM 的竞争学习机制。
    *   当一个文档落入某个格子，它会“拉动”这个格子及其邻居的向量向自己靠拢（更新 $w$）。
    *   同时，它还会更新该层级的**相关性预期值 ($\gamma$)**。如果某一层放入了很多低相关的文档，这一层的 $\gamma$ 就会自动降低。
    *   这保证了最终的地图既在拓扑结构上平滑（相似的在一起），又在径向分布上准确（中心的确实是最相关的）。

### **Part 5: 总结 (Conclusion)**

**[Slide 13: Summary]**
总结一下，VADIS 通过 **PAM 模型**实现了文档向量随“需”而变，通过 **Relevance-preserving Map** 解决了可视化中“相关性缺失”的问题。这种结合了深度学习（Attention）与可视化算法（SOM）的思路，为大规模文档探索提供了一个非常优雅的解决方案。
