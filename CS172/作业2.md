NCC ∈ [-1,1]，值越大（接近 1）表示越相似。优化器执行“最小化”目标，所以需要把“最大化 NCC”转换为“最小化损失”。取负后：

- 原本想最大化 ncc ⇒ 等价于最小化 (-ncc)
- 当 ncc → 1 时，-ncc → -1（更低的损失）
- 当 ncc → 0 或负数时，-ncc 变大（损失高）

loss2：平滑正则
```
    def gradient_loss(self, flow):

        """

        Smoothness regularization using gradient penalty

        Encourages smooth displacement fields

        """

        # Compute gradients in x and y directions

        dy = torch.abs(flow[:, :, 1:, :] - flow[:, :, :-1, :])

        dx = torch.abs(flow[:, :, :, 1:] - flow[:, :, :, :-1])

        return dx.mean() + dy.mean()
```
dx.mean() + dy.mean()作为正则项，惩罚相邻像素位移跳变，让流场更平滑
- flow[:, :, 1:, :] 取从第1行到最后一行 (去掉最上边那一行)。

- flow[:, :, :-1, :] 取从第0行到倒数第二行 (去掉最下边那一行)。

二者逐元素相减 => 每个位置是原来第 i+1 行与第 i 行的差，得到沿 y 方向的相邻差分，尺寸为 (B,2,H-1,W)。


这次作业里GPT给的总loss是这两者loss带上参数相加。（quick做法是mse）
