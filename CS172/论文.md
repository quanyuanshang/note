   def estimate_world_alignment(eef_poses: torch.Tensor, cam_poses: torch.Tensor, handeye_T: torch.Tensor) -> torch.Tensor:

    """

    使用手眼标定结果 (handeye_T) + 匹配的机械臂/相机位姿对，估计 Dust3r world -> Robot base 的整体刚体变换。

    """

    eef_poses = _ensure_torch(eef_poses)

    cam_poses = _ensure_torch(cam_poses)

    handeye_T = _ensure_torch(handeye_T)

  

    cam_inv = torch.linalg.inv(cam_poses)

    candidates = eef_poses @ handeye_T @ cam_inv

  

    R_avg = _average_rotation(candidates[:, :3, :3])

    t_avg = candidates[:, :3, 3].mean(dim=0)

  

    world_pose = torch.eye(4)

    world_pose[:3, :3] = R_avg

    world_pose[:3, 3] = t_avg

    return world_pose

# **Calibration and Coordinate Alignment**

Our system estimates the rigid transformation between the camera and the robot end-effector through a classical hand–eye calibration formulation. The transformation ( \mathbf{X} ), referred to as `handeye_T` in our implementation, represents the pose of the camera expressed in the end-effector coordinate frame. During the calibration pipeline, Step 4 invokes the function `run_calibration()`, which solves a set of relative-motion equations of the form  
[  
\mathbf{A}_i , \mathbf{X} = \mathbf{X} , \mathbf{B}_i,  
]  
where ( \mathbf{A}_i \in SE(3) ) denotes the relative motion of the robot end-effector between two time steps, and ( \mathbf{B}_i \in SE(3) ) is the relative motion of the camera reconstructed by Dust3R for the corresponding image pair. Solving this set of nonlinear equations yields ( \mathbf{X} = \texttt{handeye_T} ), the camera-to-end-effector rigid transformation used throughout the alignment process.

Once the hand–eye transformation is obtained, the system estimates the global alignment between the Dust3R world frame and the robot base frame. This is achieved by the function `estimate_world_alignment`, which computes the rigid transformation ( \mathbf{T}_{W} ) satisfying  
[  
\mathbf{T}_{W} \approx \mathbf{T}^{\text{eef}}_i , \mathbf{X} , (\mathbf{T}^{\text{cam}}_i)^{-1},  
]  
for all synchronized robot–camera pose pairs. Here ( \mathbf{T}^{\text{eef}}_i ) is the end-effector pose measured in the robot base frame, and ( \mathbf{T}^{\text{cam}}_i ) is the Dust3R camera pose after scale correction. The expression above corresponds to the construction  
[  
\texttt{candidates} = \texttt{eef_poses} ;; @ ;; \texttt{handeye_T} ;; @ ;; \texttt{cam_inv},  
]  
in the implementation. Each candidate matrix estimates the mapping from the Dust3R world coordinate system into the robot base system. To obtain a stable and globally consistent solution, the rotations of all candidate matrices are averaged using an SVD-based projection onto ( SO(3) ), while their translations are averaged component-wise. This produces a single transformation  
[  
\mathbf{T}_{W} = \texttt{world_pose},  
]  
which represents the final Dust3R-world-to-robot-base alignment.

After the calibration and alignment are completed, the transformation ( \mathbf{T}_{W} ) is applied uniformly to the camera poses and the reconstructed dense point cloud. Given any point ( \mathbf{p} ) in the Dust3R world frame, the aligned point ( \mathbf{p}' ) in the robot base frame is obtained through  
[  
\mathbf{p}' = \mathbf{T}_{W} , \mathbf{p},  
]  
implemented in `transpose_poses_ptc` via homogeneous transformation. This step ensures that all reconstructed geometry, camera trajectories, and robot motions reside in a common physical coordinate frame, enabling consistent visualization, validation, and downstream analysis.
